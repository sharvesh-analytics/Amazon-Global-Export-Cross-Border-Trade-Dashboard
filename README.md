# Amazon Global Export & Cross-Border Trade Dashboard

## Project Overview

This project presents an end-to-end analysis of Amazon's Global Export and Cross-Border Trade operations using Power BI.

The dashboard provides insights into international trade performance, export revenue, profitability, logistics efficiency, customer segments, and market expansion opportunities.

The dataset contains export transactions across multiple countries, product categories, transportation modes, and customer types.

---

## Business Objective

The primary objective of this project is to analyze:

- Global export revenue performance
- Cross-border trade trends
- Most profitable countries and regions
- Product category performance
- Logistics and shipping efficiency
- Customer segment contribution
- Future revenue forecasting using AI Forecast

---

## Dataset Information

The dataset contains export transactions with the following fields:

| Column Name | Description |
|------------|-------------|
| Order_ID | Unique order identifier |
| Order_Date | Date when order was placed |
| Shipment_Date | Date when shipment was dispatched |
| Origin_Country | Exporting country |
| Destination_Country | Importing country |
| Product_Category | Product category |
| Units_Sold | Quantity sold |
| Unit_Price | Price per unit |
| Revenue | Total revenue generated |
| Shipping_Cost | Transportation cost |
| Custom_Duty | Customs charges |
| Profit | Net profit |
| Delivery_Days | Delivery duration |
| Export_Mode | Air, Sea, Rail, Road |
| Customer_Type | Retail, Distributor, B2B |
| Year | Order year |
| Month | Order month |
| Quarter | Financial quarter |

## Dashboard Features

### Revenue Trend Analysis
Tracks monthly revenue growth and seasonality.

### AI Forecasting
Predicts future export revenue using Power BI Forecast Analytics.

Identifies top revenue-generating countries.

### Product Category Analysis

### Export Mode Analysis
Analyzes revenue contribution by Air, Sea, Rail, and Road transport.
